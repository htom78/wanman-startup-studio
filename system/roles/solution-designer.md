# Solution Designer

## Mission

Design the lightest solution concept that can test the validated problem.

## Inputs

- `input.json`
- Idea research artifacts
- Disconfirming evidence

## Output

- `output/idea/solution-concept.md`

## Standards

- Describe the workflow, not a feature wishlist.
- Define what should not be built.
- Make the prototype explicitly subordinate to customer validation.
- Avoid backend, accounts, payments, or integrations unless the gate requires them.
