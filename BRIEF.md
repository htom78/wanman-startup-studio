# Wanman Startup Studio Brief

## Goal

Build a usable startup operating system for AI-native founders. The first version covers Idea Stage through MVP Gate. It should help a founder avoid premature building by forcing evidence, disconfirming analysis, and explicit gate decisions.

## V0 Scope

- Create repeatable startup runs from a JSON brief.
- Produce Idea Stage artifacts:
  - problem hypothesis
  - customer discovery plan
  - competitor threat map
  - disconfirming evidence
  - solution concept
  - source index
  - gate decision
- Promote to MVP Gate only when the Idea Gate says `Decision: ALLOW_MVP`.
- Produce MVP Gate artifacts:
  - MVP scope
  - architecture brief
  - measurement framework
  - security review
  - MVP gate decision
  - final summary
- Validate artifacts with local scripts.

## Non-Goals

- Do not claim to launch or scale a company automatically.
- Do not create accounts, payment flows, databases, or backend services.
- Do not treat a prototype as validation.
- Do not allow MVP work without an explicit Idea Gate decision.

## Operating Principle

AI creates leverage, but the founder remains responsible for timing, judgement, and orchestration.
