# MVP Module: Scope Control

This module translates an approved Idea Gate into a tightly bounded MVP Gate.

## Inputs

- Idea Gate decision
- Problem hypothesis
- Customer discovery plan
- Competitor threat map
- Disconfirming evidence
- Solution concept

## Outputs

- MVP scope
- Architecture brief
- Measurement framework
- Security review
- MVP Gate decision

## Gate role

The module prevents "AI can build it" from becoming the reason to build. The output must explain the first user task, what is deliberately out of scope, and how first-user evidence will be measured.
